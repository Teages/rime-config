# reference/

本目錄收錄以 git submodule 引入的參考倉庫，供 Agent 查閱，**只讀**。

| 倉庫 | 來源 | 說明 |
|------|------|------|
| `rime-wiki/` | [rime/home.wiki](https://github.com/rime/home/wiki) | Rime 官方 Wiki，涵蓋方案配置、拼寫代數、自定義指南等 |
| `squirrel/` | [rime/squirrel](https://github.com/rime/squirrel) | 【鼠鬚管】源碼與內置配置，包含默認皮膚、配色方案等 |
| `rime-ice/` | [iDvel/rime-ice](https://github.com/iDvel/rime-ice) | 霧凇拼音方案，提供拼音輸入的詞庫與方案配置 |
